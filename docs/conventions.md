## conventions

- dotnet coding conventions are followed throughout the project.
  - use PascalCase for class names.
  - use camelCase for method names.
  - use UPPER_SNAKE_CASE for constants.
  - use _camelCase for private fields.
  - use camelCase for public fields.
  - use camelCase for local variables.
  - use PascalCase and start with an "I" for interface names.

- mef coding conventions are followed throughout the project.
  - use PascalCase for MEF export and import attributes.
  - use camelCase for MEF import and export property names.
  - use PascalCase for MEF import and export method names.
  - use camelCase for MEF import and export field names.
